Documentation

Fireasset is a lightweight inventory management system built as a student project — track stock, vendors, and team access from one dashboard.

Getting started

  1. Sign in with a Google account that's been added to the system by an administrator.
  2. Once signed in, you land on the dashboard, showing stock KPIs, recent activity, and value by brand.
  3. Use the sidebar to navigate to Stock, Vendors, or Users — each with a table view and an add form.

Core features

  • Stock tracking — every item has a serial number, brand, cost, owner, and location. Fields are editable inline from the table.
  • Low / high stock alerts — items below their minimum or above their maximum are flagged automatically, and a notification is sent to a Discord channel.
  • Google sign-in — access is controlled by a whitelist; only emails already registered as active users can log in.
  • Filters — every table supports filtering by its most relevant fields (name, email, product, vendor, owner, quantity, cost).

Tech stack

Node.js and Express power the backend, PostgreSQL (hosted on NeonDB) stores the data, and the frontend is plain HTML, CSS, and JavaScript with Bootstrap for layout.

Source code is available on GitHub.
